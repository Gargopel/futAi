# Roadmap

## Near Term

- Improve match filtering and search across all list screens.
- Add bet editing with richer settlement metadata.
- Compare user bets against generated analysis suggestions.
- Add bankroll charts and monthly performance summaries.
- Add duplicate-team normalization between providers.

## Medium Term

- Add more competitions beyond Campeonato Brasileiro Serie A.
- Add provider health checks and sync logs.
- Add automated odds capture when a reliable source is configured.
- Add export reports for bets, analysis history and bankrolls.

## Long Term

- Multi-user authentication.
- Cloud deployment mode.
- Model-assisted pattern analysis using historical bets and analysis outcomes.
- Scheduled sync jobs.
