# Release v0.1.0

Initial public release of FutIA Local.

## Highlights

- Local statistical football analysis for Brazilian Serie A workflows.
- Real fixture imports through API-Football and Football-Data.org.
- Manual bankroll and bet journal with profit/ROI tracking.
- Backtesting and configurable analysis rules.
- CSV/JSON import tools for local data enrichment.

## Validation

```text
php artisan test
npm run typecheck
npm run build
```

## Upgrade Notes

This is the baseline release. There is no previous schema to migrate from.
